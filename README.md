# Safe Space Saturdays

Fullstack starter generated by the Low-Token Codex CLI Harness.

## Stack

- `web/`: TanStack Start, Router, Query, React, TypeScript, Vite
- `api/`: FastAPI, Pydantic Settings, async SQLAlchemy, Psycopg 3, Alembic
- `db`: PostgreSQL 18.4 through Docker Compose
- `graphify-out/`: ignored local knowledge graph

The backend contract is documented in [`api/API.md`](api/API.md); interactive OpenAPI docs are available at `http://localhost:8000/docs`.
The UI quality loop and prioritized enhancement backlog are documented in [`web/UI_QUALITY.md`](web/UI_QUALITY.md); run `cd web && npm run ui:check` before review.

## Run the full stack in Docker

```bash
docker compose up --build
```

Open [http://localhost:3000](http://localhost:3000). The website source is bind-mounted into the web container and Vite hot reloads changes automatically. The API source is bind-mounted too, with Uvicorn reload enabled. PostgreSQL, FastAPI, and the web server are all included in the Compose stack.

Stop the stack with `Ctrl+C` or `docker compose down`. Database data remains in the named `postgres-data` volume.

## Start

```bash
cp .env.example .env
docker compose up -d db

cd api
uv sync --all-groups
uv run alembic upgrade head
uv run uvicorn app.main:app --app-dir src --reload
```

In another terminal:

```bash
cd web
npm ci
npm run dev
```

Open `http://localhost:3000`. API docs are at `http://localhost:8000/docs`.

The frontend is currently mock-data only and implements the eight supplied redesign references. Visual captures run at the reference viewport (`1672x941`):

```bash
cd web
npm run visual:capture
```

Captures are written to `web/test-results/visual/`. Asset sources and attribution notes live in `web/public/assets/ATTRIBUTIONS.md`.

## Verify

```bash
cd web && npm run verify
cd api && uv run ruff check . && uv run mypy src && uv run pytest
docker compose config --quiet
graphify query "How does web health data reach PostgreSQL?" --budget 800
```

Run `graphify update .` from this app root after relevant code changes.
