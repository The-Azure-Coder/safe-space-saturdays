# Together original visual set

These WebP assets were generated specifically for Safe Space Saturdays and are not copied from Crystal Caper or any other game.

- `together-robot-sprite.webp` — temporary eight-frame cooperative robot atlas.
- `together-beginning-backdrop.webp` — original layered platformer environment reference for The Beginning.

The visual direction is informed by Crystal Caper’s public presentation: crisp pixel silhouettes, layered parallax scenery, readable collectibles, moving-platform routes, checkpoints, and biome variation. Together keeps its own characters, maps, cooperative mechanics, networking, and Safe Space Saturdays integration.
